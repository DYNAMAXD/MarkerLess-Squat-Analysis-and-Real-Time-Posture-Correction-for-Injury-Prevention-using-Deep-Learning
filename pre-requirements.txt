# IMPORTANT: this pin is only relevant if you're on ZeroGPU hardware, which
# enforces a fixed list of torch builds (2.8.0 / 2.9.1 / 2.10.0 / 2.11.0).

# code (torch 1.x/1.11-era) — this is the best compatibility bet among the
# allowed versions, but not a guarantee.
#
# Also read the ZeroGPU note in SETUP.md before relying on this Space on
# ZeroGPU hardware at all — this pipeline calls AlphaPose/MotionBERT as
# separate subprocesses, and ZeroGPU's GPU grant is scoped to the exact
# @spaces.GPU-decorated call in the SAME process, not to child processes
# it launches. Standard GPU hardware (T4/L4/A10G) sidesteps this entirely
# and doesn't need this specific torch pin — feel free to use a newer one
# there if AlphaPose's build allows it.
