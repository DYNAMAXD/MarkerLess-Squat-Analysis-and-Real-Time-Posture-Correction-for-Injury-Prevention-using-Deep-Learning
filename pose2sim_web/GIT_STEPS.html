2. Check yourself (safe, changes nothing)

Open the repo folder in VS Code (File -> Open Folder), then Terminal -> New Terminal (or use cmd/PowerShell in the folder).

cd "C:\Current_Mini_Project_Working\MarkerLess-Squat-Analysis-and-Real-Time-Posture-Correction-for-Injury-Prevention-using-Deep-Learning"

Meaning: git fetch only downloads news (safe). In status -sb, if the first line ends with [behind N] then there is something to pull; if there is no brackets, you are up to date.

3. Go to the right branch

I suggest putting pose2sim_web on squat-error-study (where your study and your friend's work are). The alternative is a new branch (step 3B).

If git answers "untracked working tree files would be overwritten" or "local changes would be overwritten": stop, do not use --force, copy the message and ask Claude. (It would be the modified .gitignore. In that case first run git restore .gitignore.)

Optional: throw away my extra .gitignore lines (not needed):

5. Commit and push

(If you used 3B, push with git push -u origin pose2sim-web.) The commit message can be anything clear.

VS Code way: left bar -> Source Control (branch icon). Click the + next to the files under pose2sim_web (or hover the folder and click +), type a message, click Commit, then Sync Changes / Publish Branch.

If something goes wrong

  • Push says "rejected": someone pushed first. Run git pull, then push again. Never use --force without asking.
  • Pushed a wrong file: tell Claude, do not try to delete history alone.
