Painted saliency templates, one per squat error: <error>_saliency.json
(format of mesh_saliency_painter.html: {"mesh_name": ..., "vertex_count": 6890, "saliency": [6890 values]}).

The mesh viewer (start_mesh_viewer.ps1) overlays a template on every recording whose error_performed
contains an error with the same name (case, spaces and punctuation ignored). Upload them on the viewer
page or copy them here.
