3. What this means

  • The six correct … heel_lift classes each keep a different number of recordings. The smallest classes limit how reliable their per-class scores are, so quote per-class F1 with care.
  • Neck-missing recordings are dropped from the main result and kept for a robustness run (data.max_trunk_missing: null).
  • “Odd-duration” reps are only flagged, not removed: a slow or fast rep can be a real part of the movement.
  • If the six not-processed recordings can be recovered from the F: drive, run build_manifest.py, build_dataset.py and this report again.
